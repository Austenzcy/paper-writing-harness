# 科学严谨性与版本保护

## 不可静默改变的内容

原始估计值、样本量、有效样本定义、缺失值处理、变量单位、分母、时间范围、估计权重、标准误与聚类层级、显著性、置信区间、多重比较结论、变量及公式定义。EE、PP 等缩写的含义和加权对象从本研究资料核实，不根据字母猜测；未知时标为待核验，不能互换解释。百分比与百分点、水平与对数、总体与子样本、样本均值与加权均值均分别处理。

数字矛盾时记录位置及冲突来源，请作者确认或回溯已授权的计算证据；不得为了内部一致而挑选一个数字覆盖另一处。疑点标在审查记录或编辑备注中，不把未核验数字写成最终结论。语言任务不自动授权重新估计。

## 证据强度

- 描述性变化：限定样本、时期、指标和比较基准。
- 统计显著性：不等同经济重要性；未显著不等于零效应或两组等效。不能由一组显著、另一组不显著断言组间差异显著。
- 会计分解：是恒等式或构成贡献，不等于识别出的因果机制。
- 机制假说：有理论依据仍须标注待检验；不以“可能由于”填补缺少证据的解释。
- 因果效应：必须与识别设计、识别假设和估计对象相符。发现相关性不得改写为导致、推动、抑制或证明机制。

报告方向、效应量和实际意义，并保留影响解释的关键不确定性。Holm 等调整后的结论不能被未调整 p 值替代；记录比较族、调整方法及阈值。不以移至附录为由隐藏反例、调整后不显著或改变主结论的不确定性。

## 修改与核验

文件修改前识别明确源文件，保留原件；另存未占用的版本名（如 stem_v02_YYYYMMDD），避免覆盖。重要数据及图表来源只读；文件型任务可为源文件记录 SHA-256，保存轻量变更记录。

围绕实际变化对照前后：数值和样本口径 → 权重与估计对象 → 因果措辞 → 图表/公式/交叉引用 → 引文。对调换、移动和删段同时核查是否遗失限定条件。将原稿中已经存在的问题单列，勿误报为新增错误。审查模式不创建“修订稿”，可按请求另存审查报告。

正文统一交代识别、选择、测量和外推限制，避免每句重复免责声明；但关键结论就近保留必要限定。模拟、举例、假设、真实估计、待核验结果必须可区分。不能编造数据、访谈、引用、DOI、页码或核验完成状态。
