# 引文与参考文献

中文论文固定采用 cn-paper-pdf-v2，覆盖旧版中文经济学回退格式。文献事实与显示格式分开管理；不能改变作者身份、顺序、发表状态或版本。

## 正式论文显示规则（强制）

正文、脚注、图表注、附录和文后参考文献均不显示 http://、https://、www.、doi.org 链接、裸域名网址或隐藏的可点击外部超链接。Markdown链接改为作者—年份或文献标题；Word移除外部超链接关系，PDF核查URI链接注释。网址只存于不随论文提交的独立内部来源核验记录，不放进论文附录。DOI也只存内部记录；arXiv标识号和版本号可用纯文本保留。政策和网页文献用发布机构、日期、题名、文号或发布平台识别，不以网址代替出版信息。禁止为去网址而删掉整条文献。

- 正文作者—年份制，中文语境采用中文括号及标点，如“作者（2020）”“（作者，2020）”；多人引用沿用一致的中文连接方式，不改变作者顺序。
- 英文书目：Surname, I., & Surname, I. (Year). Article Title. Journal Name, Volume(Issue), pages.
- 作者之间逗号分隔，末位作者前用 &；每位作者均为姓在前、名字缩写在后。年份置圆括号内，随后句点；文章标题不加引号，刊名/书名正体、不用斜体。英文题名按源文献核验后的标题大小写呈现，不强制改为sentence case。
- 中文书目补充规则：作者1、作者2（年份）。文章题名。期刊名，卷（期），起止页。书名号与英文引号均不添加，字体正体。此项为中文文献统一规则，源PDF未含中文书目，不冒称实测。
- 中文在前按首作者姓氏拼音排序，外文随后按姓氏字母排序；同作者按年份，必要时a/b与正文同步。源PDF只支持外文姓氏排序，混排规则为明确补充。
- 工作论文：作者格式同上，年份后为题名、机构及working paper、编号、版本日期；会议论文列会议/论文集及出版者、页码（确有时）；专著列书名、版本和出版社；arXiv列纯文本ID及version；不得编造缺字段。
- 行距、字号、悬挂缩进严格按 formatting-standards；不显示条目序号。

## 核验

建立轻量来源记录：citation_key、文献类型、作者顺序、年份、标题、出版物/机构、卷期页码或文章号、DOI、版本/状态、原始来源 URL、访问日期、核验状态。优先出版社/期刊、工作论文发布机构、arXiv 和政府原文。搜索摘要不足以核实缺失字段；未提供或查不到的字段标记待核验，不补造。直接引语需核查原文及页码；翻译版区分原版年份与所引版本。

双向检查正文、脚注、图表注及附录与书目：有引无条目、条目未被引、作者年份不匹配、同作者同年 a/b、重复条目、不同版本重复统计。区分同一文献重复引用（通常合理）与同一位置重复堆叠/书目重复。工作论文后来发表不自动替换引用版本，先确认正文使用的是哪版内容。

## 类型所需字段

| 类型 | 重点字段 |
|---|---|
| 中文或英文期刊 | 作者、年、题名、刊名、卷/期、页码或文章号；已发表/online first 状态 |
| 工作论文 | 作者、年、题名、系列/机构、编号、实际版本日期 |
| 会议论文 | 作者、年、题名、会议/论文集、编者及出版信息（如有）、页码、状态；报告不冒充正式收录 |
| 专著/章节 | 作者、年、书名、版本、出版社；章节另列编者、书名及页码 |
| arXiv | 作者、年、题名、arXiv ID、版本号/日期；明确预印本，不虚构期刊信息 |
| 政策文件 | 发布机构、文件题名、文号、发布/生效日期（区分）、官方来源 |
| 网络资料 | 责任者、题名、发布日期（未知则按目标风格标无日期）、URL、访问日期 |

DOI 有则核对目标文献，未知不猜；没有 DOI 不等于文献无效。中文论文一律按上述无网址规则输出；完整 URL 和 DOI 仅在独立内部核验记录保留。文献标题大小写调整保留专名与缩写，不机械 lower/title case。英文姓名依配置呈现姓和名缩写，作者顺序不重排。
