# 引文与参考文献

先确定本次期刊配置；默认参考 [journal-profiles.md](journal-profiles.md)，但未经核验的排版细节只是个人回退风格。文献事实与显示格式分开管理：改标点、排序或缩写不得改变作者身份、顺序、发表状态或版本。

## 核验

建立轻量来源记录：citation_key、文献类型、作者顺序、年份、标题、出版物/机构、卷期页码或文章号、DOI、版本/状态、原始来源 URL、访问日期、核验状态。优先出版社/期刊、工作论文发布机构、arXiv 和政府原文。搜索摘要不足以核实缺失字段；未提供或查不到的字段标记待核验，不补造。直接引语需核查原文及页码；翻译版区分原版年份与所引版本。

双向检查正文、脚注、图表注及附录与书目：有引无条目、条目未被引、作者年份不匹配、同作者同年 a/b、重复条目、不同版本重复统计。区分同一文献重复引用（通常合理）与同一位置重复堆叠/书目重复。工作论文后来发表不自动替换引用版本，先确认正文使用的是哪版内容。

## 类型所需字段

| 类型 | 重点字段 |
|---|---|
| 中文或英文期刊 | 作者、年、题名、刊名、卷/期、页码或文章号；已发表/online first 状态 |
| 工作论文 | 作者、年、题名、系列/机构、编号、实际版本日期 |
| 会议论文 | 作者、年、题名、会议/论文集、编者及出版信息（如有）、页码、状态；报告不冒充正式收录 |
| 专著/章节 | 作者、年、书名、版本、出版社；章节另列编者、书名及页码 |
| arXiv | 作者、年、题名、arXiv ID、版本号/日期；明确预印本，不虚构期刊信息 |
| 政策文件 | 发布机构、文件题名、文号、发布/生效日期（区分）、官方来源 |
| 网络资料 | 责任者、题名、发布日期（未知则按目标风格标无日期）、URL、访问日期 |

DOI 有则核对目标文献，未知不猜；没有 DOI 不等于文献无效。目标期刊不显示网页链接时移除正文裸 URL，并按体例决定书目显示方式，内部来源记录仍保留完整 URL。文献标题大小写调整保留专名与缩写，不机械 lower/title case。英文姓名依配置呈现姓和名缩写，作者顺序不重排。
